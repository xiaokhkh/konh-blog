## Static search

Pagefind runs after the Astro build and emits a compact search index. The browser loads that index only on the search
page, so regular article pages stay lean.

## GitHub-backed comments

Giscus uses GitHub Discussions as the backing store. It is not anonymous, but it avoids maintaining a comment database and
keeps moderation in a familiar place.

## Minimal moving parts

For a personal site, the best infrastructure is often the part you did not add. Static HTML, a generated search index, and
GitHub-backed comments cover a surprising amount of ground.
