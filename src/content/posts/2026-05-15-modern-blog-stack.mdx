## Shape of the stack

The site treats Markdown and MDX as the canonical archive. Astro renders the archive to static HTML, Pagefind indexes the
output, and deployment providers only serve the artifact.

```txt
MDX in Git -> Astro build -> Pagefind index -> Vercel or Cloudflare
```

That keeps the operational surface small. There is no database to back up, no CMS runtime to harden, and no hosted editor
that owns the only copy of the work.

## Editorial workflow

Use Obsidian, Cursor, VS Code, or a Git-based CMS. They all modify the same files. The key rule is simple: once a piece is
published, the repo becomes the source of truth.

Images live under `public/images`. When you migrate from another system, download the assets into the repo instead of
hotlinking expiring URLs.

## What to add next

Add analytics only if you read them. Add comments only if they change the conversation. Add a CMS only if the Git flow is
actually slowing you down.
